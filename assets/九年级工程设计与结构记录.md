## 分页引擎要点（v3 + 九年级 v2 增补）
- 原子组=板块/整道题/变式题；页级再平衡只整组搬移；组超一整页才在"题目|解析"边界拆
- MANUAL_PAGES 四动作（post_balance 后执行）：merge_next / pull_prev / pull_text / new_page；
  anchor_block 动态定位免页移影响；merge_next 的锚=**合并方向左侧页**上的任意块（EA-54）
- new_page 吸收升级为按单元前缀部分吸收（EA-49：整组吸收在"下一页首组近满页"场景必败留标题孤页）；
  `absorb_pages: N` 限制吸收页数（防连吞下一节同 gtitle 标题组，EA-54）；`cont` 覆盖（续）标记
- pull_prev 支持 `img_cap`（单元级图限高，est 的 img_unit_h 与 build 的 image 分支同口径，EA-54）
- IMG_MAX_H 按文件名限高仅用于全局打包意图——文件名以 rid2target 实测为准，勿按清单顺序猜（EA-48）
- post_balance 空页壳修复：group_absorb 的 del 只作用于 run 副本，
  处理完须 `slides[:] = [s for run in runs for s in run]`
- 合并可行性三重裁决：估算器网格搜索(scale×cap) → validate 0 错 → check_render 渲染实测；
  `PLAN_DEBUG=1` 可查每个锚点命中时的页 idx/title/单元
- 改 IMG_MAX_H/增删 op 后必须 diff 全片计划（块签名+SequenceMatcher），确认只有点名页变化
