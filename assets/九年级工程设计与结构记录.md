## 分页引擎要点（v3 + 九年级 v2 增补）
- 原子组=板块/整道题/变式题；页级再平衡只整组搬移；组超一整页才在"题目|解析"边界拆
- IMG_MAX_H 按文件名限高（est/build 同口径）——⚠️ 文件名以 rid2target 实测为准，
  勿按清单顺序猜（EA-46：首轮全错位一格，白缩无关图+孤儿页连锁）
- MANUAL_PAGES 四动作（post_balance 后执行）：merge_next / pull_prev / pull_text /
  new_page（+absorb_any）；anchor_block 动态定位免页移影响；改参后必须重读 plan 日志
  核对每个 op 落点（EA-47：自动打包可能抢先实现手工意图）
- post_balance 空页壳修复：group_absorb 的 del 只作用于 run 副本，
  处理完须 `slides[:] = [s for run in runs for s in run]`（EA-45）
- 合并可行性三重裁决：估算器网格搜索(scale×cap) → validate 0 错 → check_render 渲染实测
