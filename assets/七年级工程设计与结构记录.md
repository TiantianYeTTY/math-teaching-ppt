## 公式（要求 1 的实现）
- 477 个公式全部为原生可编辑 OMML：从 Word document.xml 原样提取 m:oMath，
  以 PowerPoint 原生模式嵌入：`a:p > mc:AlternateContent > mc:Choice(Requires=a14) > a14:m > m:oMathPara/m:oMath`
  + `mc:Fallback`（线性化文本：^ 上标、_ 下标、a/b 分数、√() 根号、() 括号）
- 每个公式 run 显式写入 w:sz/w:szCs（=所在段落字号）与 w:color（=所在段落颜色）
- 关键教训：裸 a14:m 会被 LibreOffice 整段丢弃；必须用 mc:AC 包裹（LO 渲染 Fallback，PowerPoint/WPS 走 Choice 的可编辑公式）

## 动画（要求 7 的实现）
- 每页过渡：mc:AC 包裹的 p:fade，p14:dur=250ms（Fallback spd=med）
- 内容按拍渐显：p:timing 主序列，每拍一次点击（presetID=10 淡入 300ms + set visibility）
- 拍的划分：题干（含选项/题图/图注/子问）= 第一拍；答案、解析逐段、逐项拆解表、易错点、
  策略等每块一拍；共 257 拍；标题/页脚静态
- 尾拍与首拍永不合并（题干先出现，再逐步出答案）

## 分页引擎（防溢出/防空白）
- 估算器：CJK=1em、ASCII=0.56em、公式=Σm:t×0.62+1.8em；行高 1.42×字号 + 段后距；表行按列宽估算行数
- 打包：追加单元仅接受 ≥0.94 档；题干放不下→整块移新页，仅"页上只剩题图/新页仍放不下"才拆块分拍
- 16 行易错表按 0.94 档拆两页（续页重复表头）
- 再平衡：末页 <35% 向前页借尾单元；稀疏页向后页借首单元；**一律不跨标题上下文**（变式题绝不混页）
- 覆盖率校验：Word 每个非空段（含纯公式段/纯图片段）必须恰好出现在某一页且文本逐字一致

## 工程链路（.workbuddy/ppt_rebuild_七年级/）
- scripts/extract_docx.py → extract/content.json + media/（文档顺序遍历，文本/OMML/图/表）
- scripts/plan_slides.py → plan/slides.json（单元切分→拍分组→打包→再平衡）
- scripts/build_pptx.py → out/*.pptx（python-pptx + lxml 手写 a:p / a14:m / 表格 / timing / transition）
- scripts/validate.py → 8 项硬校验（覆盖/公式数/图片比例/字体/色板/过渡/时序/越界）
- 视觉验收：soffice 转 PDF + pymupdf 出图逐页目检；本机 LO 无中文字体，
  已把 Hiragino Sans GB 软链进 LO 字体目录用于渲染验证（交付文件仍是微软雅黑）
- 测试构建支持环境变量：PPT_FONT（渲染验证用 Hiragino Sans GB）、PPT_OUT（输出路径）
