# 格式硬规则（用户要求逐条展开 · 每条可执行可验证）

来源标注：U1–U8 = 用户最初 8 条要求；UA–UF = 过程追加反馈；EA-n = 错误档案条目。

## U1 公式全部 LaTeX（原生 OMML 可编辑）
- Word 中所有 `m:oMath` 原样提取，**禁止手打线性文本冒充公式**。
- 嵌入形态（PowerPoint 原生写法，逐字一致）：
  `a:p > mc:AlternateContent > mc:Choice(Requires="a14"，xmlns:a14 与 xmlns:m 声明在 Choice 开标签上) > a14:m > m:oMathPara/m:oMath`，同级 `mc:Fallback`（线性化文本）。
- 每个公式 run 的字号/颜色与所在段落一致。
- 验证：validate E 项（公式数一致）+ 逐 Choice 检查 `xmlns:a14` 声明（EA-2/EA-3）。

## U2 内容逐字镜像 Word
- 全部文本 run（含粗体/斜体/上下标）、表格单元格、图注、页眉原文照搬；**严禁改写、提炼、遗漏**。
- 纯公式段、纯图片段同样入片（曾被"无文本"过滤丢段，EA-9）。
- 验证：validate D 项覆盖率 100%（按段落聚合比对，不按 run）；check_plan dup blocks 为空。

## U3 排版清晰、无大面积空白、无挤压、字号适中
- 正文 16pt / 表格 12pt / 页标题 22pt（超长自动降 20/18pt）/ 封面标题 40pt。
- 缩放档 [1.0, 0.94, 0.9, 0.86, 0.82]；页内追加组最低 0.9 档，整组放置/拆块最低 0.86 档。
- 页面填充：<40% 的页只允许"组完整不拆"的自然结果，出现即检查再平衡参数。
- 内容底边 ≤7.00in（规划容量 5.60in 已含余量）。

## U4 图片等比、限尺寸
- 按 Word extent 原始宽高比缩放（校验 ±1%）；限高 2.2in、放大≤1.6 倍；窄小图可放大至宽 3.5in。
- 相邻两张题图 → imgpair 左右并排（限宽 5.9in 各占半栏，图注居中在图下）；UA：上下堆叠浪费左右面积。
- 连续多张题图**不吸入题干单元**（否则双图无法同页，EA-7）。

## U5 字体/颜色统一
- 全片单一字族（默认微软雅黑），a:latin/a:ea 双绑定；色板白名单：
  标题 1A237E / 正文 1A2230 / 答案·引导词 3E6FC9 / 警示 D9534F / 图注 5A6472 /
  页脚 8A93A6 / 边线 D6DCE5 / 表头底 F5F7FA / 隔行 F7F9FC / 白 FFFFFF。
- 蓝色语义白名单（UF 审计口径）：答案行整行、粗体引导词（≤24 字且到冒号）、标题行/变式标题行粗体 run、板块行粗体段、封面标题。**正文编号"（3）"与括号说明必须正文黑**（EA-6）。
- 表格：表头加粗 F5F7FA，数据行白/F7F9FC 严格隔行，0.75pt D6DCE5 全边框；表格外禁着色。

## U6 每页"Oli教室"署名
- 右下角 `PPT_FOOTER · 页码/总页数`（10pt 灰 8A93A6），每页必带。验证：validate C 项。

## U7 过渡 + 逐拍动画
- 每页 p:fade 250ms（mc:AC 包裹，Fallback spd=med）。
- 拍划分：题干（含选项/题图/图注/子问）= 第一拍；答案、解析**逐段**、拆解表逐项、易错点各一拍；标题/页脚静态；尾拍与首拍永不合并。校验：validate B 项拍数=计划、spid 全存在。

## U8 内容完整不中途换页 + 稀疏并页
- 原子组=板块/整道题/变式题；组放不下整组移下一页；仅组超一整页时在"题目|解析"边界拆（拆块首页可吸收待合并小页）。
- 超长题干超任何档位 → 按块（图/图注/原题/各小问）拆流入。
- 页级再平衡只**整组搬移**，绝不跨标题上下文（变式题绝不混页，EA-5）。
- 同页多组间 GROUP_GAP=0.42in 空行（UA：多题同页要有空行）。
- 表格超页 → 均衡分行块（续页重复表头）。

## 过程追加规范（UA–UF）
- **UA 删除章节独占页**：大标题不得单独成页，只作内容页页首标题（EA-1）。
- **UB 封面**：无装饰横条；大标题文字与字号按用户指定（七年级案例："上海市七年级上学期期中数学复习课" 40pt）。
- **UC 分层行高**：含 m:f/m:rad/m:nary（分式/根号/求和）的段落行高 1.95 倍；仅上标/线性 1.58 倍。一刀切 = 全片稀疏 + 图题分离（EA-10）。
- **UD 双图并排**：见 U4。
- **UE 同页多组空行**：见 U8。
- **UF 颜色 run 级审计**：交付前解包 pptx 逐 run 扫描 srgbClr，蓝色清单逐条对照语义白名单（EA-6 专属防线）。
